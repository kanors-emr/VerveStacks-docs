How a VerveStacks model is built

Six short films, one model

Each film takes one part of a VerveStacks country model and shows how it is made from open data. They run about two minutes each, with narration. Watch in order, or jump to a section.

The films show the method with real pipeline outputs for the chosen country. Narration starts when you press play. India does not have a CO₂ storage film yet. VerveStacks is built by KanORS-EMR.
