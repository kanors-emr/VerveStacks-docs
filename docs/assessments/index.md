# Assessments

**Using a reference model to answer a specific question**

A reference model is the starting point. An assessment is what a user does with it: change a few assumptions, run, and compare against the reference. The pages in this section describe three common assessments in the same way:

- **What is in the model today** that the assessment can use, with no extra work.
- **What the user sets**, because it is a judgement or a policy choice the pipeline should not make.
- **What it can show**, and **what is not built yet**.

| Assessment | The question | Page |
|---|---|---|
| Nationally Determined Contributions | What does it take for the power sector to meet the country's climate pledge and renewable targets, and what does it cost? | [NDCs and national targets](ndc.md) |
| Demand disruption | What happens when a large new load, such as a cluster of data centres, arrives faster than planned, and where? | [Demand disruption](demand-disruption.md) |
| Supply disruption | What happens when a fuel becomes scarce or expensive, a plant goes offline, or a dry year hits hydro? | [Supply disruption](supply-disruption.md) |

Because every country is built to the same template (see [The Reference Model](../methods/reference-model.md)), an assessment set up for one country carries over to another with the same steps.

!!! note "Status"

    These pages describe how the models support each assessment today. Worked examples with results will be added as they are run and reviewed.
