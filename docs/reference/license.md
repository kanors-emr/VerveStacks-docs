# Open‑Use License

**Usage terms and attribution requirements**

## In short

- **Use it.** Run, change, extend and teach with any VerveStacks model, within the permitted uses below.
- **Your version is yours.** A model you modify, the scenarios you add and the results you produce belong to you. They do not have to be published and can stay private.
- **Credit the base.** If you publish results from a VerveStacks model, cite VerveStacks and the model version. If you redistribute a model, document your changes; commercial redistribution needs permission.
- **The pipelines are not part of the release.** The software that generates the models is maintained by KanORS-EMR; see the [FAQ](../getting-started/faq.md).

## License Terms

### Permitted Uses

- Research and academic analysis
- Policy development and evaluation
- Educational and training purposes
- Non-commercial consulting and analysis

### Attribution Requirements

- Cite VerveStacks and specific model version
- Reference data sources and methodology
- Include model limitations and assumptions
- Provide link to documentation

## Restrictions

- Modifications must be clearly documented
- Quality and validation standards must be maintained
- Attribution requirements cannot be removed
